Reflection

ปัญหา/ความท้าทายที่พบ:ยังไม่คุ้นกับ HTML/CSS เพราะเพิ่งเริ่มเรียน ไม่รู้ว่าอะไรไหนควรใช้ตอนไหนอย่างไร รู้สึกกดดันเพราะเป็นงานที่ต้องทำส่งแลกคะแนนเลยกังวลว่าจะมีส่วนที่ทำผิดไหม [ไฟล์เปิดไม่ได้ รูปไม่ขึ้น งงว่าต้องทำอย่างไรเลยถามAIดูจนสามารถเปิดแสดงไฟล์รูป]

สิ่งที่เข้าใจมากขึ้น: [ทำให้เข้าใจว่าเว็บไซต์หนึ่งหน้าประกอบด้วย HTML ที่เป็นโครงสร้างเนื้อหา กับ CSS ที่ทำหน้าที่จัดรูปแบบให้สวยงาม โดยทั้งสองไฟล์ต้องแยกกันแต่ก็เชื่อมโยงกันด้วยและรู้ว่าการจัดโฟลเดอร์ให้เป็นระเบียบมีผลโดยตรงต่อการที่เว็บไซต์จะแสดงผลได้ถูกต้องหรือไม่]

อยากพัฒนาต่อ: [อยากลองเพิ่มรูปภาพหรือเนื้อหาที่เป็นของตัวเองมากขึ้น และอยากศึกษาการจัดวางหน้าเว็บให้ดูเป็นระเบียบกว่านี้ เพราะตอนนี้ยังใช้ CSS ได้ไม่หลากหลายมากนัก]
